The module is a documentation-driven Claude Code skill composed of three layers: (1) `SKILL.md` — the primary skill manifest defining name, description, trigger keywords, end-to-end integration workflow (identify scenario → recommend flow → generate code → onboard → troubleshoot), two booking flows (Flow A: Search→Verify→Order→Pay; Flow B: GetOffer→Order→Pay), authentication, status codes, retry strategy, ancillary services, webhooks, post-booking operations, and FR-specific handling; (2) `references/` — supporting reference documents split by concern (`flow-quick-reference.md` for endpoint call sequences, `integration-scenarios.md` for sandbox test routes and UAT matrices, `mcp-integration-guide.md`, `code-generation-guide.md`, `common-issues.md`) so the skill can cross-reference detailed content without bloating the main file; (3) `test-prompts.json` — a small fixture of sample prompts with expected responses used to validate skill behavior. The skill delegates precise schema/error-code lookups to an external MCP service (`resources.atriptech.com/~gitbook/mcp`) with a documented fallback chain (MCP → WebFetch → built-in knowledge). There is no executable code — the module's architecture is purely instructional, structured as a self-contained knowledge base consumed by the Claude Code agent at runtime.
