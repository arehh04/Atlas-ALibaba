The root holds the project blueprint (`blueprint.md`) that defines a two-layer architecture: a FastAPI backend exposing disruption/consensus webhooks and an SSE stream, backed by a LangGraph `StateGraph` of four agents (sentinel → profile/scout in parallel → arbiter) with optional HITL breakpoints, plus a Vue 3 dashboard frontend. The child module `atlas_integration_advisor_skill` is a Claude Code skill that guides clients through integrating with the same Atlas Sandbox API used by the swarm's scout agent. Cross-child cohesion comes from the shared Atlas Sandbox contract (search_flights / book_pnr) and the external n8n webhook channel that bridges user WhatsApp responses back into the paused graph thread.
